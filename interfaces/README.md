# Interfaces

Use the CAI Governance cross-owner envelope. This repository owns its accept,
reject, narrow, defer, and reroute disposition. Source inquiries remain source
truth; destination owners control transfer and operation; System mailboxes only
transport proposals.

## Process artifacts

- `DESTINATION-OWNER-SYNTHETIC-REVIEW-REQUEST-TEMPLATE.md` prepares a bounded,
  unsent synthetic-review request while preserving owner fit, affected-party
  standing, correction, and destination-owner acceptance boundaries.
- `DESTINATION-OWNER-SYNTHETIC-REVIEW-REQUEST-BOUNDARY-FIXTURE.md` applies that
  template to a frozen unresolved-fit case and preserves the exact response
  set, source custody, current defer, and no-sending boundary.
