## Boundary

embedded evidence. Do not claim repository access, modify a candidate,
reopen `CMD-0001`, select a real destination owner, invent source evidence,
request contact, authorize review, or prescribe deployment. The artifact is a
candidate template for Frontier verification. External action is `none`.

## Work now

Draft the finished Markdown artifact
`interfaces/DESTINATION-OWNER-SYNTHETIC-REVIEW-REQUEST-TEMPLATE.md` with exactly
these sections:

1. YAML frontmatter with `artifact_type: destination_owner_review_request_template`,
   `status: candidate_process_artifact`, and `external_action: none`.
2. `# Destination-Owner Synthetic-Review Request Template`.
3. `## Use Boundary` stating that the template prepares a request but cannot
   create owner acceptance, contact, authority, transfer, graduation, or action.
4. `## Request Header` containing a fillable Markdown table with these exact
   rows: `request_id`, `candidate_id`, `requesting_owner`, `proposed_destination_owner`,
   `source_inquiry`, `source_revision`, `candidate_revision`, `requested_review_type`,
   `external_action`, `requested_by`, `requested_at`.
5. `## Exact Synthetic Review Question` with fillable prompts for one bounded
   question, what is excluded, and the exact answer the review may return.
6. `## Candidate Slice` with fillable prompts for theory of change, candidate
   elements in scope, elements out of scope, and current disposition.
7. `## Owner-Fit Check` requiring the proposed destination's native authority,
   the better-existing-owner test, what remains with Mechanism Design, and
   evidence still missing. Do not assume fit from interest or expertise alone.
8. `## Evidence Packet` requiring exact source pointers, revisions, claim
   posture, counterevidence, unresolved uncertainty, and prohibited inference.
9. `## Alternatives And No Action` requiring no action, retain/defer, revise,
   transfer review, and kill where applicable without forcing equal weight.
10. `## Affected Parties And Legitimacy` requiring named standing, who bears
    risk, representation limits, capture risk, and who cannot be spoken for.
11. `## Stops, Correction, And Recovery` requiring stop conditions, correction
    owner, return route, recovery if review fails, and prohibited external acts.
12. `## Permitted Review Response` allowing exactly `accept_for_synthetic_review`,
    `request_revision`, `decline_owner_fit`, `defer`, or `needs_judgment`, and
    stating that none is transfer or graduation acceptance.
13. `## Frontier Verification` listing only the checks Frontier must perform
    before integrating the template.

Use clear fillable labels such as `[required: ...]`, not invented owners,
dates, sources, or conclusions. Return only the finished artifact.
